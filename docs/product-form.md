# 06 产品形态：本地图示

版本DIA-PF-1，2026-11-07。状态：产品方向已确认，功能未实现；独立评审状态见[评审报告](references/design-review-surfaces.md)。本页集中保留用户已有决定，不再逐项询问内部机制。

| ID | 最终目标与首版范围 | 状态/来源 |
|---|---|---|
| DIA-PF-01 | 从Agent对话生成/讲解本地图，且在本地可视化编辑、保存与再打开；两个入口可独立启用，首版两者都要 | 用户集中Q06答复“图生成/讲解＋本地可视化编辑” |
| DIA-PF-02 | skill编排证据范围与解释；plugin拥有Harness编辑界面、文档版本和保存；不重新实现代码索引 | 既有形态与本轮设计决定；不冒称已开发 |
| DIA-PF-03 | 优先复用已有Atlas离线图；默认自有受限SVG编辑器；经完整锁定/兼容/出口审计的Archify/Drawio可后续替换实现 | 设计默认，来源与机制见[软件设计](software-design.md)第2节 |

用户旅程：在聊天中指定路径/模块或概念→查看带来源、置信及未知标记的本地图→打开Harness图示编辑→拖拽、添加说明、概念节点/annotation边→保存本地新修订→重开或undo/redo。生成结果是解释产物，手工修改不提高代码关系可信度。

自动行为限登记范围内的schema/来源/版本校验、布局和保存守卫；用户选择范围、编辑、导出及冲突合并。冲突保留旧版和草稿，不盲覆盖；未就绪明确blocked；停用/卸载保留本地文档。默认导入外部XML为conceptual，原位覆盖任意外部文件后置，以本工具不可变新修订保存。

可见产物：HTML/SVG、`.drawio`、manifest、base/annotation JSON、来源/版本/未知说明。后置复杂形状、多页、多人协作、任意图片/HTML导入；无公共图服务、云导出、远程字体图片或额外模型服务。未来局部新增按DIA需求ID和[局部修订规则](references/design-change-policy.md)，只重核受影响的产品范围。
